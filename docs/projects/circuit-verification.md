# AI-Based Circuit Verification Automation

[← Profile](../../README.md)

> 공개 증빙 준비 문서입니다. 검증된 구현 사례나 완성 성과를 의미하지 않습니다.

## Overview

사용자 제공: 삼성전자 기업연계 AI 회로 검증 자동화 프로젝트. 정식 재직 경력이 아닌 기업연계 프로젝트로 분류합니다.

## Problem

공개 가능한 문제 정의와 실제 요구사항을 정리할 자료가 필요합니다.

## My Role

담당 역할·기간·공개 허용 범위는 확인 대기입니다.

## System Architecture

공개 가능한 아키텍처 자료가 없어 다이어그램을 임의 제작하지 않았습니다.

## Implementation

BOM 파싱·구조화, Netlist 분석, 연결 관계 모델링, 요구사항 해석, 규칙 검증, 판단 근거 추적은 검토할 증빙 항목입니다. 구현 완료 사실로 확정하지 않습니다.

## Verification

확인할 자료: 본인 담당 작업 기록, 외부 공개가 허용된 설명, 비식별 예제와 검증 절차. 기업 내부 코드·실제 BOM·Netlist·고객 문서·식별 가능한 화면은 첨부하지 않습니다.

## Results

정확도·생산성·수상 등급 등 확인된 공개 성과는 없습니다. 수상·전시는 주최기관, 행사명, 연도, 등급, 공식 링크 또는 공개 가능한 증빙을 확인한 뒤 추가합니다.

## Lessons Learned

회고를 뒷받침할 본인 의사결정과 트레이드오프 기록이 필요합니다. 확인 전에는 기술적 성과·교훈을 작성하지 않습니다.
